# 喵撲 Meowpuut 0.4.3 Alpha 1

這次把 macOS、Windows、Android 收到同一個版本，主要整理「句子還沒打完，候選卻退回第一個字」的問題。

## 輸入與詞庫

- 拼音、注音會保留多個可選前段。選完前半句，剩下的讀音繼續組字；下一個音節只打一部分時，也能繼續選前面的句子。
- 中日混打保留中文前段，例如 `jinwandeyueliangkirei`。完整的混合句不再被只覆蓋開頭的單字擠走；注音本版仍專注中文長句。
- mimo 1.0 重新核對單字讀音、繁簡字形、重複資料及來源衝突。更新 McBopomofo 固定快照，保留繁體異體與不同讀音；簡體模式使用簡體來源的詞頻，避免繁體同音詞的權重直接蓋過去。
- 上下文調整只在覆蓋同一段讀音的候選之間進行，避免短前段因記憶加分跳到完整長句前面。macOS、iOS 可使用游標前的短段中文，以及本機已確認的選詞記憶。
- 超出組字容量時保留原始讀音再繼續，避免新按鍵無聲消失。

## 各平台

- **macOS：** 修正待上屏文字在模式切換、試打頁重繪和空組字時的處理；保留雙貓／簡潔皮膚、深淺色與玻璃強度設定。需要 Apple silicon、macOS 27+。
- **Windows：** 更新 TSF 輸入服務和同版詞庫，加入繁簡切換、標點與焦點／待送文字保護。實際系統輸入法目前支援拼音，注音尚未接入。x64 套件包含安裝腳本與雙貓渲染器。
- **Android：** 更新共享核心、詞庫與拼音／注音分段，修正換欄位、游標移動及長按時的待送文字處理；調整橫向和分割視窗的鍵盤尺寸。需要 Android 7+。
- **iOS：** 同步核心與分段修復，整理鍵盤尺寸、長按刪除、空格移動游標和鎖屏恢復。提供原始碼，本次不發布 IPA 或 TestFlight。

## 下載與更新

從[本版下載頁](https://github.com/Krysta1ll/Meowpuut/releases/tag/v0.4.3-alpha.1)選擇平台；各檔案的 SHA-256 收錄於同頁的 `SHA256SUMS.txt`。

macOS 首次安裝可用紙箱安裝盤；更新請執行其中的「安裝或更新.pkg」。儲存工作、登出再登入後，到系統設定加入 Meowpuut。Windows 完整解壓後執行 `Install.cmd`，完成後重新開啟使用輸入法的應用程式。Android 安裝 APK 後到系統鍵盤設定啟用喵撲。

**Android 0.1.0 使用者：** 舊版簽署私鑰不在目前建置環境，本版使用新的專用發行金鑰，無法直接覆蓋更新。請先記下設定，再卸載舊版、安裝新版；卸載會清除本機設定。新的金鑰保存在本機私有目錄，不包含在原始碼或下載包中。

## 測試範圍與還沒解決的事

本輪通過 macOS 915 項冒煙檢查、核心組字狀態與候選分段回歸，以及 iOS、Windows、Android 的可攜邏輯測試。這些測試不等同所有應用程式的實際輸入；Windows、Android 尚未完成真機驗收。評估樣本、方法及未解問題記在[輸入體驗紀錄](INPUT_EXPERIENCE_AUDIT.md)。

長句首選率仍有改善空間，少見讀音與高度歧義的句子可能需要分段選字；解碼搜尋範圍也可能提前排除適合上下文的詞。日語以小型詞表及假名轉換為主，不能代替完整日語整句輸入法。Windows 的 Enter、刪除和游標操作與待送文字的順序尚未全面驗證；應用關閉或拒絕寫入時，各平台仍可能遺失未提交文字。

macOS 套件未經 Developer ID 簽署或 Apple 公證，Windows 套件未簽署。Windows 渲染器沿用源碼未變的前版公開二進位，本輪重建 TSF DLL 與詞庫；套件內 `BUILD-INFO.md` 列出來源和驗證範圍。

# 喵撲 Meowpuut 0.4.2 Alpha 1

這次更新著重長句分段、候選排序和中日混打。

- 拼音與注音在長句尚未打完時保留可選的前段；選取後，尚未轉換的讀音留在組字中。
- 改善拼音中日混打的分段和候選排序，例如「今晚的月亮」後接 `kirei`。注音仍專注中文輸入。
- 有日語候選時，收合列會保留一項，以小貓爪標示；展開後依候選排序瀏覽，不再固定放在最右邊。
- 拼音組字時可按空格選取高亮候選，Shift＋Enter 輸出原始字母；注音空格保留大千一聲。
- 擴充詞庫與上下文關聯，調整候選窗的長句顯示，並保留雙貓、簡潔皮膚與玻璃強度設定。

## 安裝

macOS 測試包支援 macOS 27 或更新版本的 Apple silicon Mac。首次安裝可使用紙箱安裝盤，更新請使用安裝盤內的「安裝或更新.pkg」或單獨的安裝套件。完成後儲存工作、登出再登入，再到系統設定加入 Meowpuut。下載後可用 `SHA256SUMS.txt` 核對檔案。

測試包未使用 Developer ID 簽署，也未經 Apple 公證，macOS 可能阻止開啟。請先讀[安裝說明](https://github.com/Krysta1ll/Meowpuut/blob/main/docs/INSTALL.md)。

iOS 提供原始碼，尚無公開 TestFlight 或 IPA；本次候選修改尚未完成真機驗證。Windows 目前提供可攜核心，尚無 TSF 輸入法或安裝包。長句排序、繁簡字形和跨 App 相容性仍在測試；日語以單字和假名為主，不是完整日語整句輸入法。

# 喵撲 Meowpuut 0.4.1 Alpha 1

這次更新整理了候選窗、詞庫和幾個常用按鍵。

- 雙貓和簡潔皮膚新增深淺色、六組配色與三段玻璃強度。
- 拼音可用 Shift＋空格／6／3／4／7 輸入一、二、三、四聲與輕聲；單按 Shift 切換中英。
- 中文模式可按 Option＋斜線輸入 `/`。注音的 ㄥ 與原本的問號按鍵保留原位。
- 改善長組字的候選窗定位，以及非美式鍵盤和小鍵盤 Enter 的處理。
- 補充日常、社群與網絡用語，調整上下文和整句選詞；拼音可將 `wosukini` 分成中日混合候選。
- 紙箱安裝盤可用於首次安裝；更新舊版請使用「安裝或更新.pkg」。

## 安裝

需要 macOS 27 或更新版本，以及 Apple silicon Mac。下載安裝盤或安裝套件，完成後請儲存工作、登出再登入，再到系統設定的輸入來源加入 Meowpuut。更新不會移除本機選詞記憶。下載後可用 `SHA256SUMS.txt` 核對檔案。

本測試包未使用 Developer ID 簽署或 Apple 公證，macOS 可能阻止開啟。請先讀 [安裝說明](https://github.com/Krysta1ll/Meowpuut/blob/main/docs/INSTALL.md)。

## 還在測試

長句排序、繁簡字形及不同 App 的候選定位仍可能出錯；非美式實體鍵盤和新的定位修復尚待更多實機測試。日語目前以單字與假名為主，尚不能完整轉換日語長句。本次只提供 macOS 安裝包，iOS 和 Windows 仍在開發。
