# 喵撲 Meowpuut 0.8.0

這一版四個平台一起發布：iPhone、iPad 是 TestFlight 0.8.0（9），Mac、Android、Windows 是 GitHub 上的 0.8.0 Alpha 1。下面先寫四個平台都有的改變，再分平台寫。iPhone 是和 0.7.0（8）比，Mac 是和 0.6.0 Alpha 1 比，Android 是和 0.1.0 Alpha 比，Windows 是和 0.1.1 Alpha 比。

## 米米莫和莫莫換了新的樣子

- 兩隻貓換成照著牠們的照片做的黏土公仔造型，App 圖示和標誌也一起換了。
- 牠們把前爪搭在候選玻璃的上緣：身體在玻璃後面，爪子在玻璃前面，不擋到字。
- iPhone 和 Mac 上，牠們每天換一個地方待：兩端各探一顆頭、擠在同一邊、整隻趴在上面等八種，當天不變。設定的「位置」可以固定一種；某個寬度或玻璃形狀放不下的位置，會改用放得下的一種。Android 和 Windows 是兩端各一隻。
- iPhone 和 Android 上，摸米米莫，他會縮一下、搖搖頭；摸莫莫，她會蹭一下。連摸莫莫五下，切換繁體和簡體。Windows 見下面。
- 到了一些節日，兩隻貓會換上節日的衣服，選中候選的顏色也跟著換。iPhone 在喵撲 App 的「節日衣櫥」關掉，Mac 和 Android 在「節日裝扮」關掉。Windows 這一版只換選中候選的顏色。

## 詞庫與授權

- 拼音裡的英文詞重新數過，只數人寫的文字。iPhone、Google、Facebook 的大小寫對了；IG、ID、LINE 這類縮寫另外寫了一份清單。
- 米米莫和莫莫的圖、App 圖示、標誌和節日的圖保留所有權利：可以從這個倉庫建置喵撲自己使用，其他用途見 `ASSETS-LICENSE.md`。程式和資料仍是 MIT。

Mac、Android、Windows 上一次發布時，iPhone 還沒有 0.7.0。所以 0.7.0 詞庫和授權的改變（見下面 0.7.0 的第一節），這幾個平台是這一版才拿到：

- 語料換成我們自己收集和撰寫的。
- 新收約 5.8 萬個作品、角色、地名等名稱，和約 2 萬個各行業用詞。
- 含政治、貶低某一群人等用語的句子，不拿來計數。
- Mac 0.6.0 Alpha 1 是 GPL-3.0，這一版改回 MIT。

## iPhone、iPad

- 舊的貓會眨眼、有尾巴；新的貓不眨眼，也沒有尾巴。
- App 裡多了一頁隱私政策。
- 「開源授權」頁寫明程式是 MIT、貓的圖保留所有權利。

## Mac

- 候選列的玻璃照四個平台共用的規格重調：邊緣多一圈折光，下半部透出一點顏色，選中的候選像一顆染色的玻璃珠；深色外觀的邊框和光跟著配色走，不再固定是銅色。
- 表情符號和顏文字換成和 iPhone 同一份資料，排在候選清單所有詞的後面。

## Android

這是 0.1.0 之後第一個 Android 版，整個重寫過。

- 選字改用和 iPhone、Mac 相同的 Rust 核心、詞庫和詞對表：整句時除了看一個詞常不常用，也看前後兩個詞常不常接在一起。
- 候選列是一條玻璃，米米莫和莫莫在兩端。玻璃有膠囊、波浪、雲朵三種形狀，淺色、深色或跟著系統，六組配色，三段玻璃強度，也可以把貓關掉。
- 拼音、注音、日語三種輸入方式，繁體或簡體。拼音裡打完整的羅馬字，候選會有帶貓爪的日文詞（`sushi` 的「寿司」），日文詞表是幾百個審過的詞。
- 按鍵之間沒有點不到的空隙；兩指交替快打不掉字；按住刪除鍵會越刪越快；按住空白鍵左右滑可以移動游標；Shift 連按兩下鎖定大寫；長按字母有重音字母。
- 震動跟著系統的鍵盤觸感設定，App 裡也可以關；按鍵聲預設關閉。
- 換了簽署用的金鑰。裝過 0.1.0 的話，要先移除舊的才裝得上。
- 最低版本從 Android 7.0 改成 8.0，而且只有 64 位元（arm64、x86_64）的版本。

## Windows

- 這一版又是一個可以安裝的 Windows 輸入法。安裝檔沒有簽署。
- 候選窗重做，照四個平台共用的規格：一條玻璃，米米莫和莫莫在兩端探頭，前爪搭在玻璃上。點米米莫，他會縮一下、搖搖頭；點莫莫，她會歪一下頭；連點莫莫五下切換繁體和簡體。淺色、深色預設跟著 Windows 的「應用程式模式」。
- 這種視窗拿不到背後的畫面，沒辦法做模糊，所以玻璃接近不透明，只有外緣一圈是透明的。
- 選字改用和其他平台相同的 Rust 核心和詞庫，但還沒有用詞對表，也沒有選詞記憶；日文詞表是幾百個審過的詞。

## 還在測試

回報問題時，請附平台和版本、輸入模式、按了哪些鍵、想打什麼、實際出現什麼。

已知的問題：

- Android 沒有選詞記憶，也沒有表情符號和顏文字；日文詞表比 iPhone、Mac 小很多。
- Android 版只在模擬器上試過，還沒有在實機上打過字；節日的衣服在 Android 上還沒有實際看過。
- Windows 輸入法還沒有在真的 Windows 上從安裝一路試到打字。
- Mac 的安裝檔沒有經過 Apple 公證，Windows 的安裝檔沒有簽署。
- iOS 17、18 的霧面玻璃樣式還沒有在這兩個版本的實機上看過。
- 0.7.0 列的選字問題有兩個還在：`huaxue` 先出「滑雪」，`nihao` 的候選裡還有「逆號」這種不像詞的詞條。`wuli` 現在先出「物理」。

# 喵撲 Meowpuut 0.7.0

以下是 iOS 測試版 0.7.0（8）的內容。

## 詞庫與授權

- 語料改成我們自己收集和撰寫的：哪個詞常接哪個詞、詞的常用程度、常單獨說的短語，從喵撲自己寫的約 20.6 萬句話，加上 Tatoeba、Common Voice 和三份對話資料數出來。
- 含政治、貶低某一群人、辱罵等用語的句子不拿來計數，鍵盤不會在短語和聯想詞裡主動給這些詞；自己要打仍然打得出來。
- 新收約 5.8 萬個名稱（動畫、漫畫、遊戲與角色、影視、藥品、食物、地名、車站等，來自 Wikidata）和約 2 萬個各行業用詞（醫療、法律、會計、軟體、製造、動畫製作、餐飲等）。打完整個詞才會出現。
- 首選正確數和改之前相當：評測集注音 830／845、拼音繁體 922／993、拼音簡體 918／994（改之前 831、917、918；Apple 鍵盤 821、902、912）；另外兩組句子（各 1,401 與 600 句）注音 1121 與 469、拼音繁體 944 與 388、拼音簡體 955 與 399（改之前 1120 與 466、956 與 382、968 與 395）。
- 喵撲的程式改以 MIT 授權發佈。

## 表情符號和顏文字（iOS）

- 打「開心」這類詞，候選列第二格是 😊，第三個詞後面多一個顏文字 (\*´▽`\*)；這個詞其他的表情符號和顏文字在展開面板的「表情」。空白鍵和 Return 仍只送出詞。
- 選詞之後，候選列第一格是那個詞的表情符號，接著是聯想詞，第二個表情符號和顏文字排在第三個聯想詞後面：「生日快樂」後面第一格是 🎂。前面有「不、沒」的不給：「不想睡」不會出現「想睡」的表情。
- 符號頁的 `^_^` 鍵移到最下排，兩個符號頁都有，不再只是輸入 ^_^ 三個字：點一下，候選列換成顏文字，最近用過的在前；箭頭展開面板，20 組共 377 個。點了就輸入，列表留著；再點一次 `^_^` 或打字就關閉。
- 有表情符號的日常用詞從 56 個增加到 1,644 個（繁體和簡體分開算），日語詞有 936 個（すし 🍣、ありがとう 🙏）；另外用了 Unicode CLDR 的日語表情註解。
- 點過的表情符號或顏文字，下次排在那個詞的最前面。關掉「記住選詞」就不記。
- macOS 候選清單裡的表情符號和顏文字用同一份資料，排在所有詞後面。

# 喵撲 Meowpuut 0.6.0

這次更新重做了介面，也換了選字的方式。四個平台改用同一份設計規格（`docs/DESIGN.md`）；以下是 iOS 測試版 0.6.0（7）的內容。

0.6.0（7）修正鍵盤太矮的問題：先前鍵盤要的高度沒有送到宿主 App，在 Instagram 等 App 裡只拿到系統預設的 216 點，候選列和按鍵都被壓扁。現在每個 App 裡都是完整高度，按鍵和內建鍵盤一樣高。

按鍵改回液態玻璃，並且跟著色系染色：淺色是帶一點色系的珠光白，深色是帶色的煙色玻璃。

候選列的玻璃重新調過：邊緣多一圈折光，下半部隔著玻璃透出一點焦散的顏色，選中的候選像一顆染色的玻璃珠。深色外觀的邊框和焦散不再固定是銅色，跟著色系走。macOS、Android、Windows 的候選列照同一份規格。

鍵盤的底板多了一層很淡的色系顏色，候選列底下有一塊柔光。底板本身是系統的，改不了，所以候選列後面沒辦法做成透明。

最低系統版本從 iOS 27 降到 iOS 17。iOS 26 之前沒有液態玻璃，候選列是霧面玻璃，按鍵是帶色系的實色鍵面。這套樣式只在 iOS 27 模擬器上強制切換看過，還沒有在 iOS 17、18 的機器上跑過，需要測試者回報。

0.6.0（6）修正了（5）的兩個問題：當成系統鍵盤使用時，最下面一排按鍵被系統的地球鍵那一列蓋住；鍵盤自己畫的底色蓋掉了系統的玻璃背板，候選列後面一片黑。現在鍵盤不畫底色，按鍵是半透明的，高度照系統給的範圍排。

## 候選列和兩隻貓

- 候選列是一條液態玻璃。米米莫在左端、玻璃後面，眼睛露出上緣；莫莫在右端、玻璃前面，下巴擱在上面。
- 玻璃有膠囊、波浪、雲朵三種造型，各有淺色和深色，在喵撲 App 的鍵盤設定裡選。
- 候選永遠排成一行，日語候選不再被擠成直排。太長的整句候選在中間以「…」省略，完整內容在展開面板。
- 中文輸入時，收合列最多放一個日語候選，後面有貓爪記號；日語模式顯示全部候選。
- 候選列可以左右滑動看更多候選。按右邊的箭頭展開成面板，可以只看詞組。
- 展開面板在手機上一排六格：單字一格，詞佔兩三格。
- 收合列變寬：候選從米米莫身前的玻璃開始，展開鍵收到莫莫下巴下方，一般手機上一次看得到四到五個詞。
- 常用詞後面有對應的表情符號，例如「你好」後面是 👋；點了才輸入，空白鍵和 Return 仍送出詞。
- 沒有輸入時，候選列放常用標點（，。？！、）；選詞之後顯示聯想詞。
- 兩隻貓會眨眼。摸米米莫，他會縮一下、搖搖頭；連摸莫莫五下，切換繁體和簡體。
- 節日裝扮在節日前才加入，平時是原本的貓。設定裡可以關掉。

## 打字

- 按鍵之間沒有點不到的空隙，點在兩個鍵中間算最近的鍵。
- 兩指交替快打不會掉字：第二指按下時，第一指的鍵立刻送出。
- 按下的同時出現放大的鍵帽。手指滑到別的鍵，放開時輸入最後停留的鍵。
- 長按英文字母出現重音字母，長按標點出現其他寫法，滑動選取；不滑動就放開，輸入原來的鍵。
- 符號頁打 3.14、12:30 不會中途跳回字母；空白、撇號和中文句讀之後才回字母。繁體的符號頁有「」。
- 按住刪除鍵連續刪除，約 2.5 秒後改為整詞刪除。
- 按住空白鍵 0.4 秒後，左右滑動移動游標。組字中按住空白鍵，仍是選詞或一聲。
- Shift 點一下大寫一個字母，快點兩下鎖定大寫。拼音鎖定大寫時直接輸入大寫字母，例如 NBA。
- 拼音組字時按 Return（確認）送出打的字母，例如 nihao、iPhone；空白鍵選第一個候選。注音的 Return 送出選中的候選。
- 組字在文字欄裡分音節顯示：拼音「ni hao」，注音「ㄋㄧˇ ㄏㄠˇ」。
- 注音只打聲母也能找詞，例如 ㄋㄏ 有「你好」；不再出現 sc 這類按鍵字母。
- 按鍵聲跟隨系統的「鍵盤回饋」設定。鍵盤不要求「完整取用」，所以沒有按鍵震動。
- 鍵盤一出現就能按。詞庫在背景載入，這段時間按的鍵會照順序補上。
- 英文（ABC）時候選列有正在打的字的補完和拼字建議，點了才換；空白鍵不會自動改字。
- 支援橫向和 iPad，也支援 VoiceOver、降低動態效果、降低透明度、增加對比和粗體文字。

## 選字

- 句子的選字除了看每個詞常不常用，也看前後兩個詞常不常一起出現。長句和口語句子比上一版準。
- 詞的常用程度加進了日常對話的統計，日常用語不再輸給書面的同音詞，例如「炒飯」和「超凡」、「下課」和「俠客」。
- 拼音裡可以直接夾英文：`wozaiyongiphone` 是「我在用iPhone」，`xiazaipdf` 是「下載PDF」。
- 拼音打完整時，補全和錯字修正不會蓋過它：`haola` 是「好啦」，不是「好萊塢」。
- 全拼和首字母可以混著打：`zenmb` 是「怎麼辦」，`buzd` 是「不知道」。
- 第一個候選後面依序是同音的整詞、前面幾個音節的詞、第一個音節的單字。選了前面的詞，後面的讀音留著繼續選，接下來的詞會參考剛選的詞。
- 沒有前後文時，「他／她／它」先出「他」，「你／妳」先出「你」，句尾的「嗎／嘛」先出「嗎」。
- 很長的句子打到後面不會變慢。
- 詞庫改成直接讀檔，不再整份載入記憶體。鍵盤在模擬器上約用 28 MB，上一版拼音約 63 MB。
- 和 iOS 內建鍵盤比第一個候選，用本專案自己出的 2,832 題日常詞句：注音 831／845（內建 821），拼音繁體 917／993（內建 902），拼音簡體 918／994（內建 912）。上一版是 782、711、716。題目是自己出的，分數偏樂觀。另一組不是本專案寫的 600 句（取自 Tatoeba）沒有內建鍵盤的數字，只能和上一版比：注音 466（上一版 404），拼音繁體 382（上一版 232），拼音簡體 395（上一版 238）。

## 喵撲 App

- 首頁有米米莫和莫莫的 15 張生活照。點開可以放大，可以存到「照片」或分享。照片不帶拍攝地點和相機資料。
- 鍵盤設定頁上方的預覽和鍵盤畫的一樣。
- 鍵盤不需要「完整取用」，不連網。選詞記錄留在鍵盤自己的空間。
- 鍵盤設定頁最下方的「開源授權」列出詞庫和表情符號資料的授權全文。

## 還在測試

真機上的記憶體用量、觸控手感和不同 App 裡的表現還需要測試者回報。日語仍以單字和短語為主，不是完整的日語整句輸入法。回報問題時，請附輸入模式、按了哪些鍵、預期文字、實際結果和機型。

已知的問題：

- 少數常用詞單獨打時第一個候選不對，例如 `huaxue` 先出「滑雪」、`wuli` 先出「屋裡」。
- 拼音夾英文有時把兩三個字母當成英文縮寫，例如 `ie` 先出「IE」而不是「家」。英文詞的大小寫照語料裡最常見的寫法，所以有些普通詞是大寫開頭，例如 Project。
- 候選列裡還有少數不像詞的詞條，例如 `nihao` 的「逆號」。
- 打到一半時，句尾兩個字母可能短暫被當成英文，例如 `nihaok` 會先閃一下「你哈OK」，繼續打就恢復。

# 喵撲 Meowpuut 0.5.0 Alpha 1

這次更新把解碼核心改寫成 Rust，詞庫改成三層，並重做了 iOS 鍵盤。

## 1. Rust 解碼核心

- 核心改寫成 Rust 工作區（`meowpuut-core`、`meowpuut-lexicon`、`meowpuut-client`、`meowpuut-ffi`），不再使用 C++ 實作，全部 `#![forbid(unsafe_code)]`。
- 資料用陣列結構體（SoA）排列，工作區（`DecodeScratch`）預先配置，解碼迴圈裡不配置記憶體；拼音按鍵延遲中位數約 `0.21 ms`。
- 補齊拼音模糊音／鍵鄰糾錯（`zh/z`、`ch/c`、`sh/s`、`n/l`、`in/ing`、`en/eng`、`an/ang` 及雙字相鄰換位）與注音缺聲母、韻母近似、漏聲調容錯。

## 2. 三層 `mimo` 詞庫（`mimo-tc`、`mimo-sc`、`mimo-jp`）

- **第一層（離線建置）**：繁體、簡體、日語各整理成一個詞庫檔（`mimo-tc.json`、`mimo-sc.json`、`mimo-jp.tsv`），來源是 **McBopomofoData**（MIT）、**OpenCC**（Apache-2.0）、**jieba**（MIT）、**霧凇拼音 `rime-ice`**（GPL-3.0）、**pinyin-pro**（MIT）與 **UniDic**（BSD-3-Clause）。分數統一成 `i16` 對數機率，編譯成唯讀二進位檔 **`mimo_base.bin`**（`MIMO-BASE-1` / `MIMO-BIN-1`）。
- **第二層（唯讀詞庫）**：iOS 鍵盤和 macOS 用 `mmap`（`.mappedIfSafe`）讀 `mimo_base.bin`，啟動時不必解析整份文字詞庫。
- **第三層（使用者記錄）**：鍵盤把選詞、造詞和退格記錄追加到 `mimo_user_wal.log`，App 再把它併入 `mimo_user.db`。

## 3. iOS 鍵盤

- 按鍵行為比照 iOS 內建鍵盤：放大的鍵帽、按下立即變色、連按兩次空格輸入句號、長按刪除鍵加速刪除、長按空格移動游標，以及下拉展開的多欄候選面板。
