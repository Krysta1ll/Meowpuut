# 喵撲版本怎麼看

Android、macOS 和 Windows 的正式版使用「**名稱 · 構建代碼**」。例如「稜鏡 · 26A019」中，`26` 是系列起始年份，`A` 是該年的第一個發布系列，`019` 是 Android 的構建序號。各平台分開累計，更新時不歸零。

「窗邊」系列：

| 平台 | 名稱 | 正式版 |
| --- | --- | --- |
| Android | 稜鏡 Prism | 26A019 |
| macOS | 窗臺 Sill | 26A033 |
| Windows | 門廊 Porch | 26A003 |
| iPhone、iPad | 露珠 Dew | App Store／TestFlight 使用 Apple 的數字版號 |

GitHub 標籤包含平台、名稱和構建代碼，例如 `android-prism-26a019`。安裝檔保留名稱與構建代碼，例如 `Meowpuut-Prism-26A019.apk`。[前往下載](../README.md#下載)

## 更新說明

各平台的更新說明用「小貓們的密謀」短對話。米米莫活潑、愛演，會伸爪、說「喵」或「nya」。莫莫用簡短、冷靜的回話接住他的玩笑，順勢說清楚操作。公開版本的玩笑留在兩隻貓之間，對話用具體例子交代這一版確實改了什麼。

版號、適用裝置、下載方式和實際發布狀態另外用直述寫清楚。QQ 群用簡體中文「小猫们的密谋」，可把同一段對話縮成幾句放上公告圖。

## QQ 粉絲群公告圖

每次發版都交付一張給 QQ 群使用的簡體中文 PNG。沿用米米莫、莫莫原版素材、實際鍵盤截圖和喵撲的配色，直接排版，圖片保留版本號、主要改動及各平台的實際發行狀態。

- iOS 已送審時，標示「已送审，正在等待 Apple 审核」。確定上架後再改為 App Store 可下載。如已設定自動發行，可加「审核通过后自动上架」。
- Android 正式 APK 可供下載時，標示「已发布，现在到群文件下载 APK」，同時交付簽署 APK 的下載連結，供群管理員上傳或貼在公告下方。APK 放進群檔案後，公告圖即可轉發。
