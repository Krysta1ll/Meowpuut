# 喵撲版本怎麼看

Android、macOS 和 Windows 的正式版使用「**名稱 · 構建代碼**」。例如「稜鏡 · 26A012」：`26` 是系列起始年份，`A` 是該年的第一個發布系列，`012` 是 Android 的構建序號。各平台分開累計，更新時不歸零。

「窗邊」系列：

| 平台 | 名稱 | 正式版 |
| --- | --- | --- |
| Android | 稜鏡 Prism | 26A012 |
| macOS | 窗臺 Sill | 26A032 |
| Windows | 門廊 Porch | 26A002 |
| iPhone、iPad | 露珠 Dew | App Store／TestFlight 使用 Apple 的數字版號 |

GitHub 標籤包含平台、名稱和構建代碼，例如 `android-prism-26a012`；安裝檔保留名稱與構建代碼，例如 `Meowpuut-Prism-26A012.apk`。[前往下載](../README.md#下載)
