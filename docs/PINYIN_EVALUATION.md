# 拼音候選評估

`scripts/eval-pinyin-holdout.py` 使用固定的人手編寫題目，分別檢查單字、詞組、整句和分段。找到指定候選時，腳本也會選中它，檢查上屏文字及未選部分是否保留。報告包含測試資料、核心和詞庫的 SHA-256。

```sh
python3 scripts/eval-pinyin-holdout.py --set development
python3 scripts/eval-pinyin-holdout.py --set validation --json
```

題目不包含與本地人工詞條或上下文完整相同的目標，但來源詞庫仍可能包含同詞或其中的片段。題目由人手挑選，同音輸入往往不只一個合理答案；以下是指定目標在這批題目的名次，不是準確率，也不能代表真實用戶的輸入分布。

## 搜尋範圍比較

在同一份開發集上，將長句搜尋寬度由 5 增至 12，可選完整整句由 12 題增至 14 題，但首屏由 12 題減至 11 題；本機長句逐鍵測試的 P95 約由 8 ms 增至 33 ms。因此目前保留 5。這是本機比較，不代表手機效能；需要更廣的語料與真機測試，才能判定其他搜尋策略。
