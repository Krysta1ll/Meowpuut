# 按鍵聲

同一組音檔供 iOS 與 Android 使用。

所有聲音由 `scripts/key_sounds.py` 照公式算出來（只用 Python 標準函式庫，每次跑出的檔案一模一樣），沒有取樣、錄音或第三方音檔。檔案在 `assets/key-sounds/<組>/<聲音>-<變體>.wav`，44.1 kHz、16 位元、單聲道；量測表是同一資料夾的 `measurements.md`，腳本每次重寫。

```
python3 scripts/key_sounds.py                      寫音檔和量測表；有一組不合標準就結束碼 1
python3 scripts/key_sounds.py --ref click.wav      順便量一個參考音檔
python3 scripts/key_sounds.py --page audition.html 順便寫試聽頁（範本是 scripts/key_sounds_page.html）
```

量測用來比較音量、頻譜和連打時的餘裕。

## 六組

每組五種聲音：一般鍵、空白（低一點、圓一點）、刪除（短一點、乾一點）、換行（兩個音，一個小小的收尾）、選字（輕一點）。一般鍵有四個變體，空白、刪除、選字各三個，換行一個；變體之間差幾音分、0.3–0.9 dB 和 ±10% 的衰減，連打時才不會像機器。

| 組 | 規則 |
| --- | --- |
| 水滴 | 氣泡的共振頻率是 3.26 m/s 除以半徑（Minnaert）：4 毫米的泡泡響 815 Hz，之後每 80 毫秒往上滑一個八度。空白 5.6 mm、刪除 4.6 mm、選字 3.3 mm；換行是 5.4 mm 接 3.6 mm 兩滴（半徑比 3:2，音高差純五度）。 |
| 木琴 | 調音木琴音條的泛音在 1 : 4 : 10，越高的泛音消失得越快。一般鍵 D5，空白 A4，刪除 C5，選字 G5；換行 A5 落到 D5。 |
| 玻璃 | 酒杯杯緣的振動模態 n = 2, 3, 4，頻率比 n(n²−1)/√(n²+1)，也就是 1 : 2.83 : 5.42。一般鍵 B5，空白 E5，刪除 A5，選字 D6；換行 E6 落到 A5。和候選列的玻璃是同一個意思。 |
| 毛氈 毛毡 | 沒有音高：白噪音經過中心 900 Hz 的帶通，音量照半個高斯鐘形 e^(−t²/2σ²) 收掉，σ = 18 毫秒。空白 600 Hz、σ 24；刪除 1000 Hz、σ 13；選字 1100 Hz、σ 13；換行兩下（600 接 900 Hz）。 |
| 五聲 五声 | 鍵越靠右音越高，音取自五聲音階的純律比 1, 9/8, 5/4, 3/2, 5/3, 2（主音 D5 = 587.33 Hz）；沒有半音，打一句話就是一段小曲。空白是低八度的 3/2（440 Hz），刪除是主音，選字是高八度主音；換行 3/2 落到 1（屬音回主音）。變體只改音量和長度，比例保持精確。 |
| 泛音 | 每個頻率都是 110 Hz 的整數倍：空白 4 倍、刪除 5 倍、一般鍵 6 倍、選字 8 倍，換行從 9 倍落到 6 倍；每個音自己的泛音（2、3 倍）也在同一條泛音列上。變體不改音高。 |

五聲的「位置」：鍵的中心距鍵盤左緣幾個鍵寬（第二排多 0.5，第三排多 1），乘 6/10 取整數，最多 5。實機鍵盤用同一條公式，硬體鍵盤照 QWERTY 位置。

### 刪掉的兩組

- **紙 纸**（中心 3 kHz 的噪音）：4 kHz 以上占 13–64% 的能量，2–5 kHz 有寬峰，400–3k 只占 12–67%，不合標準。這是預期中的：清脆的紙聲就落在耳朵最容易嫌吵的頻段。
- **黃金 黄金**（泛音 f、φf、φ²f，音量和長度每層縮小 φ 倍）：量測全部過關，但聽起來和玻璃同類（不成整數倍的鐘聲），六組裡留玻璃，因為它和候選列的玻璃是一套。它的數字仍在量測表裡，要換回來只要把 `SETS` 裡的 `False` 改成 `True`。

另外每個檔頭尾都是 0、直流低於 −80 dB（腳本檢查）。空白、刪除、換行和一般鍵的 A 加權音量差在 2 dB 內（刪除 −1 dB），選字比一般鍵輕 2–4 dB。每秒 12 鍵時最多兩個聲音重疊，另外也用每組最大的六個樣本峰值相加，確認六聲重疊仍低於滿刻度。

音量怎麼比：A 加權能量換算成 100 ms 的均方。iOS 26.2 模擬器執行環境裡的系統按鍵聲 `key_press_click.caf`（只在本機轉成 WAV 量，不進 repo）峰值 −8.5 dBFS、同樣量法 −31.6 dB；這次把自訂音色提高 5.5 dB，一般鍵量到約 −33 dB，和參考音檔相差約 1.4 dB。實際差多少還要看接進鍵盤時用哪一條播放路徑（見下面 iOS 一節），要在真機上聽。

毛氈是噪音，每個種子的起音和頻譜都不一樣。腳本從固定的種子往上找，取第一個起音 1.5–4.5 ms、本體 ≥ 26 ms、2–5 kHz 沒有凸起的；所以是照同一條規則選，不是用耳朵挑。

## 試聽頁

`python3 scripts/key_sounds.py --page …/audition.html` 把上面的 WAV 以 base64 放進頁面，用 Web Audio 解碼播放，播的就是這些檔案（約 1.7 MB）。每組一排鍵和「選字／空白／刪除／換行」，「打一句」每秒 5 鍵、「快打」每秒 10 鍵，打的是量測用的同一句；可以兩組輪流打來比較；也可以在框裡用硬體鍵盤或手機鍵盤打。音量從 −6 dB 開始。

## 鍵盤設定

- iOS 與 Android 的「按鍵聲」都可選關閉、系統或六組音色。iOS 預設系統聲。Android 會沿用舊的按鍵聲開關。
- iOS 自訂音色只在允許完整取用時載入，關閉完整取用時沿用系統聲。自訂聲音遵守裝置的靜音模式，音量跟隨裝置媒體音量和喵撲的調整。鍵盤仍在本機完成組字、選詞與記憶。
- Android 自訂音色跟隨裝置的響鈴模式及系統按鍵聲設定。震動有獨立開關和強度設定。
- 兩端都可調整自訂音色的音量。系統音色由裝置設定控制。
- 五聲用按鍵中心在整排鍵盤中的水平位置選音。空格、換行、刪除與選字使用各自的聲音。

iOS 真機驗收可在「備忘錄」分別試關閉、系統聲、六組音色，切換完整取用與側邊靜音，確認重新打開鍵盤仍照設定播放。
