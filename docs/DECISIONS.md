# 设计决定

- 2026-11-06：独立项目命名 Meowpuut，不修改 Penumbra。首版 macOS，繁简都用大千注音。
- 2026-11-06：复用 Rime 的语音转换、词库与语言模型；应用会话、候选交互、个人偏好和模块格式独立实现，不复刻 Squirrel。
- 2026-11-06：界面去掉品牌口号与宣传说明。优先处理候选选择与中英切换；不引入云端输入处理。
- 2026-11-06：先支持本地 JSON 短语模块；不先造插件市场、二进制 ABI 或主题编辑器。
- 2026-11-06：候选检索和固定词跨页召回限制在引擎前 256 项，按需展开，不逐键取长列表；只选引擎已有候选。
- 2026-11-06：中英切换保留明确控制：Shift + Space 提交当前选词并切模式，Shift + Return 恢复误输入的原文；网址/邮箱复用 Rime recognizer，不猜测普通英文字母。
- 2026-11-06：系统输入源通过 InputMethodKit 和 Carbon 公开 API 接入，Bundle ID 必须包含完整 `.inputmethod.` 段；启用由用户在应用里主动触发，不自动切换当前输入法。
