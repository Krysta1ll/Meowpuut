## 当前实现

- SwiftUI 设置/候选窗、AppKit 试打、InputMethodKit 控制器；复用 librime C API，未复制 Squirrel 应用代码。
- 繁简切换保留组合，标准注音与省略声调输入；Rime 自带词库、语言模型与用户词库。
- 7 项候选、↑↓ / Tab / ⇧Tab、⇧数字、回车整句、翻页；词组筛选和最多 256 项的按需浏览。
- 图钉固定首选、前 256 项跨页召回、繁简偏好分开、取消固定列表；显示顺序与真实候选索引统一映射。
- Shift + Space 提交当前组合并切中英；Shift + Return 恢复误打的原文。大写词、协议网址、普通邮箱使用 Rime recognizer。普通字母不猜模式。
- 本地 JSON 短语模块 API v1，支持重新加载、分页、无效文件错误；未知命令原样提交，删除 `/` 后返回普通输入。
- 用户主动触发的「启用 Meowpuut」按钮，仅启用自己的输入源，不自动选择。系统控制器已处理 commitComposition、焦点退出提交及光标范围；实际跨应用验收待完成。
