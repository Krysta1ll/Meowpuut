# 接手狀態

目前為 0.3.1 自研核心＋MIT 基礎詞庫版，架構、限制與驗證入口見 README.md、ENGINE.md。最終決策不是完全不用外部資料，而是接受寬鬆授權詞庫；Rime 不得恢復。保留來源與授權，修改另放 Resources/Lexicon。

使用者的 sushi 案例：中文「蘇軾」優先，日語「寿司」不能藏在展開後。詞量約 17.2 萬組中文讀音，日語單字表仍小，未實作日語整句句法轉換。不要沿用舊 Rime 比較成績。

2026-11-06 0.3.6：兩份 MIT 資料已合併為 `mimo-tc` 與 `mimo-sc`（簡體詞頻優先並保護繁體高頻詞），按 hans＋帶調 reading 去重，日語為 `mimo-jp`。先讀 README 的更新／記憶／標點規則。不要恢復 Rime。
