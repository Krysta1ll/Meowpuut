# 社群詞條維護

喵撲的社群詞條是人工整理的繁簡詞面、讀音及編輯優先級；它們是拼音和注音共用的中文詞庫的一部分。優先級是排序參數，不是平台的真實使用頻率。一般詞語同時有社群含義時，盡量沿用既有詞庫，避免為圈內含義改壞日常排序。

## 更新規則

目前沒有自動抓取、下載或上傳詞庫的功能。新詞先記錄公開來源與日期，再由維護者核對含義、讀音、繁簡字形、重複詞和容易混淆的日常用法，人工加入；由現有詞庫編譯與測試流程合併、去重後，隨應用版本發行。引用的文章或影片保留各自權利，不因被列為查證來源而改變其授權。

## 排序回歸

同音時保留一般用法的優先次序，例如無聲調的「課堂／嗑糖」、「股權／谷圈」、「夢想／夢向」、「理會／立繪」與「持股／吃谷」；明確輸入注音聲調仍按讀音過濾。社群詞仍需進入引擎前七個候選，以便展開查找。這只是初始詞庫的排序，個人選詞記憶和不同平台的候選顯示數量可能改變畫面。

詞庫編譯後執行 `python3 scripts/check-community-lexicon.py <編譯資源目錄>`，以真實 C++ 解碼器驗證拼音、注音和繁簡輸出，以及常見詞與圈內同音詞的先後；測試不需要網絡。新增詞彙或更新上游快照時，應同時檢查日常同音詞，不以社群詞條數量作為品質指標。

2026-11-07 加入整句測試，覆蓋日常、動漫與「一部／一步／一不」語境。以「一部動漫」「一部電影」等自然搭配改善整句，不單獨提高「一部」權重，避免影響「走了一步」和「一不小心」。這些是固定回歸例，不代表真實使用時的整句準確率。

同日新增 `Resources/Lexicon/context.tsv`，以人工審核的繁體語境片段和編輯權重補充相鄰詞的排序，例如「條魚」「部動漫」「上嗑糖」。它們只影響兩段詞接合時的加分，不會成為獨立詞條；簡體輸出也使用對應的繁體語境計算。測試同時覆蓋日常句與社群句。較長句子和冷門語境仍可能排序錯誤，不能視為完整的語言模型。

後續補入低權重的「新包」及購物語境，使「買了一個新包」等句子更容易選到；同時測試「醫生檢查心包」和「一聲巨響」，保留其他同音用法。單獨輸入 `xinbao` 時「心包」仍排在「新包」之前；不帶聲調的長句仍可能有其他歧義。
