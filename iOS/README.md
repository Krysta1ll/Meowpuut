# 喵撲 iOS

包含宿主 App 與自訂鍵盤擴充，共用 C++ 中文核心、Swift 候選排序與詞庫。需要含 iOS 27 SDK 的 Xcode、Python 3 與 XcodeGen。

```sh
brew install xcodegen
bash scripts/build-ios.sh
```

工程由 project.yml 生成，輸出在 .build/iOS。真機安裝需在 Xcode 選擇自己的開發團隊與可用的 Bundle ID；目前沒有公開 TestFlight 或可直接安裝的 IPA。

App 與鍵盤需要同一個 App Group 來共享設定。請用自己的開發團隊註冊群組，並把 `iOS/AppGroup.entitlements` 與 `iOS/SharedKeyboardSettings.swift` 內的群組識別碼改成相同的值；兩個 target 都需要使用有權限的描述檔簽署。

鍵盤 RequestsOpenAccess=false，輸入不需要完整取用權限。個人詞庫保存在擴充自己的沙盒，不與 macOS 同步。已通過模擬器目標編譯；真機記憶體、觸控、無障礙與跨 App 輸入仍需測試。

拼音、注音和日語模式可在喵撲 App 的鍵盤設定中切換；`ABC` 鍵切換英文，再按一次回到原模式。拼音和日語鍵盤可按「符號」開啟符號頁。展開候選可瀏覽和翻頁，選詞記憶會在本機自動累積。

注音鍵盤可點下方「符號」開啟符號頁，再點「注音」返回；中文模式下常用標點會直接顯示並輸入中文標點。符號頁的數字和符號會先完成當前組字再輸入，不會誤觸選詞或注音按鍵。按住刪除鍵可連續刪除；按住空格並左右滑動可移動游標，開始移動前會完成當前組字。

在喵撲 App 的鍵盤設定頁，可選擇「雙貓玻璃」或簡潔玻璃、跟隨系統／淺色／深色、三段玻璃強度及與 macOS 相同的六種色系；下次開啟鍵盤時生效。App 只向共享群組寫入明確修改的設定，鍵盤唯讀，不要求「完整取用」。尚未在 App 修改的設定會沿用鍵盤原本的選擇。選詞記錄仍保存在鍵盤自己的本機沙盒，不會放進共享群組；清除請求由鍵盤在下次啟動時執行一次。設定與記錄目前都不跨裝置同步。系統的「降低透明度」和「增加對比」會提高候選列底色的不透明度。玻璃效果會受系統合成和所在 App 影響。

雙貓皮膚把圓潤可愛的麻糬小貓與液態玻璃融合：候選列是一條通透的 Liquid Glass 膠囊長條，鍵盤底色是帶柔和珠光高光的霧面玻璃。米米莫（炭黑色、得意的半瞇眼）趴在長條左端，莫莫（重點色暹羅貓：深色面罩與耳朵、圓亮藍眼睛與小巧「ω」嘴）趴在右端。兩隻小貓的耳朵與圓頭探出玻璃上緣，保持清晰鮮明；胸口與下半身則順著漸層柔和融入玻璃長條內，並承接玻璃下緣的高光與邊框光澤。選中的候選詞是一顆帶色系色調的玻璃泡泡，候選詞前面有編號。小貓是軟萌麻糬風格點陣圖（`iOS/Keyboard/Cats.xcassets`，各有睜眼與「^ ^」兩格），由 `scripts/key_cat_sprites.py` 從綠幕原圖去背、修整輪廓、對齊並輸出 @2x/@3x。開啟「降低透明度」或「增加對比」時，玻璃改為不透明底色。

兩隻貓會不定時眨眼；組字時會看向候選詞，提交後米米莫會輕輕跳一下。輕點米米莫，他會跳起來、搖搖頭，有時還會笑。輕點莫莫，她會蹭你的手並臉紅；在約 1.6 秒內連續摸她五下，她開心了就切換簡體／繁體，候選列中央會顯示切換結果，VoiceOver 也會朗讀。切換後有約 1.2 秒的休息時間，繼續點擊不會又切回去。兩隻貓的觸摸區只在各自那一端，候選詞再往內縮一點，所以摸貓不會選到候選詞，選詞或滑動候選詞也不會摸到貓。提示框不接收觸控。選擇「降低動態效果」時，跳動和搖頭會關閉，只保留眨眼和淡入淡出。

簡體中文：鍵盤上的按鍵、提示和無障礙標籤跟隨目前輸入的字體，摸莫莫切換後立即改變；App 則跟隨系統語言（zh-Hans 顯示簡體），App 名稱在簡體系統顯示為「喵扑」。

莫莫切換的字體只保存在鍵盤本機。App 裡的「中文」選項只在你再次修改時套用一次，之後不會在每次開啟鍵盤時蓋掉莫莫的切換。
